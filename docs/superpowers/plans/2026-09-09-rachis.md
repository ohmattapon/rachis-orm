# Rachis ORM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** สร้าง `packages/rachis` v1 ตาม design ที่ล็อกไว้ (chain บางๆ + where object, AND only, guard ครบ)

**Estimated tasks:** 6 | **Estimated time:** ~120-180 min | **Touches:** ORM lib / Bun / Postgres / migrations script

## Current Problem / Current Solution

วันนี้มีแค่ `custom-orm-requirements.md` + design doc (`docs/superpowers/specs/2026-09-09-rachis-design.md`) ยังไม่มีโค้ด ไม่มี `package.json` ไม่มี `packages/rachis` ทีมยังต้องพึ่ง Prisma/TypeORM หรือเขียน SQL มือ

## Proposed Approach

สร้าง internal package `packages/rachis` แบบ TDD ทีละ slice: scaffold -> schema (whitelist+auto-map) -> builder select+where -> builder mutations+guard -> executor+raw -> repo example + integration + migration scaffold แต่ละ task ส่ง `{ sql, params }` ที่ assert ได้โดยไม่ต้องต่อ DB ยกเว้น task สุดท้ายที่รัน Postgres จริง

## Side by Side

| Scenario | Before | After |
| -------- | ------ | ----- |
| select filter | เขียน SQL string เอง เสี่ยง concat | `query(users).select(...).where({...}).toSQL()` ได้ parameterized + whitelist |
| update ไม่มี where | เสี่ยงล้างทั้งตาราง | throw `UnsafeFullTableError` ตั้งแต่ build |
| query ที่ builder ไม่ถึง | หนีไป concat string | `raw(users, sql, params)` แบบจำกัด + whitelist + ปฏิเสธ `; -- /*` |
| เทส | ไม่มี | unit assert sql+params + integration smoke ผ่าน `execute()` จริง |

## Assumptions & Risks

- **Assumed:** ใช้ Bun 1.4.x + `Bun.sql` (Postgres) เป็น driver ตรงๆ ไม่ทำ pool abstraction เอง
- **Assumed:** ใช้ Zod v3 (ถ้า repo หลักใช้ v4 ต้องปรับ import นิดหน่อย)
- **Assumed:** CI / เครื่อง dev รัน docker Postgres สำหรับ integration ได้ (`DATABASE_URL` เข้าถึงได้)
- **Assumed:** `BETWEEN` = inclusive ตาม SQL มาตรฐาน, `LIKE` ส่งค่าดิบผ่าน params (ไม่ auto-escape `%`)
- **Risk:** auto-map regex `([a-z0-9])([A-Z])` เดาชื่อประหลาด (`userID` -> `user_i_d`) ผิด -> ต้องใช้ override ราย field (ยังไม่สเปก shape ละเอียด อยู่ใน Task 2)
- **Risk:** `Bun.sql` API เปลี่ยน -> กันด้วย interface `Db` บางๆ ใน executor (mock ได้ใน unit)
- **Risk:** Task 7-scope (operator เยอะ Q7-C) ทำให้ builder+test matrix ใหญ่กว่าประมาณ ถ้าหนักไปให้ตัดกลับเป็นเซ็ตมาตรฐาน (B)

## Impact

- ทีมได้ ORM เบาๆ ใช้เอง ไม่ต้องพึ่ง Prisma/TypeORM ใน service ใหม่
- ทุก query เป็น parameterized + whitelist ลด class SQL injection จาก concat
- guard กันล้างตาราง + raw แบบจำกัดทำให้ review ง่าย
- monorepo `packages/rachis` reuse ข้าม service ได้ระยะยาวโดยยังไม่ต้อง publish registry

import { expect, test } from "bun:test";
import { z } from "zod";
import { defineTable } from "../src/schema";
import { query } from "../src/builder";

const users = defineTable("users", z.object({ id: z.number(), firstName: z.string(), age: z.number(), status: z.string(), deletedAt: z.date().nullable() }));

test("select + BETWEEN + = + IS NULL -> sql+params + auto-map", () => {
  const q = query(users).select("id", "firstName", "age")
    .where({ col: "age", op: "BETWEEN", val: [18, 30] })
    .where({ col: "status", op: "=", val: "active" })
    .where({ col: "deletedAt", op: "IS NULL" }).toSQL();
  expect(q.sql).toBe("SELECT id, first_name, age FROM users WHERE age BETWEEN $1 AND $2 AND status = $3 AND deleted_at IS NULL");
  expect(q.params).toEqual([18, 30, "active"]);
});

test("IN + NOT IN + LIKE + NOT LIKE + comparisons + IS NOT NULL", () => {
  const q = query(users).select("id")
    .where({ col: "id", op: "IN", val: [1, 2] })
    .where({ col: "status", op: "NOT LIKE", val: "%x%" }).toSQL();
  expect(q.params).toEqual([1, 2, "%x%"]);
});

test("unknown col throws + where immutable", () => {
  const b = query(users).select("id");
  expect(() => b.select("nope" as never).toSQL()).toThrow("UnknownColumn");
  const b2 = b.where({ col: "id", op: "=", val: 1 });
  expect(b2).not.toBe(b);
});
```

// packages/rachis/tests/executor.test.ts
import { expect, test } from "bun:test";
import { z } from "zod";
import { defineTable } from "../src/schema";
import { query } from "../src/builder";
import { execute, raw } from "../src/executor";

const users = defineTable("users", z.object({ id: z.number(), age: z.number() }));

test("execute passes sql+params to Db (mock)", async () => {
  const calls: unknown[] = [];
  const fakeDb = { query: async (sql: string, params: unknown[]) => { calls.push([sql, params]); return [{ id: 1 }]; } };
  const q = query(users).select("id").where({ col: "id", op: "=", val: 1 }).toSQL();
  const rows = await execute(fakeDb, q);
  expect(calls[0]).toEqual([q.sql, q.params]);
  expect(rows).toEqual([{ id: 1 }]);
});

test("raw requires params + rejects ; -- /* + uses snake names", () => {
  const q = raw(users, "age > $1 AND deleted_at IS NULL", [20]).toSQL();
  expect(q.params).toEqual([20]);
  expect(() => raw(users, "age > 20", []).toSQL()).toThrow();
  expect(() => raw(users, "age > $1; DROP TABLE users", [1]).toSQL()).toThrow("UnsafeRaw");
  expect(() => raw(users, "age > $1 -- x", [1]).toSQL()).toThrow("UnsafeRaw");
});
```
